# Portfólio — Pedro Heitor

Portfólio pessoal de Pedro Heitor, estudante de Análise e Desenvolvimento de Sistemas, com foco em desenvolvimento web, front-end e suporte de TI.

## Tecnologias do portfólio
- HTML5
- CSS3
- JavaScript
- Font Awesome
- GitHub Pages

## Como publicar
Substitua no repositório `portfolio-website` os arquivos `index.html`, `style.css`, `script.js` e `README.md` pelas versões atualizadas.

Mantenha no repositório a imagem `4f6320dc-8a06-4cdd-acfe-5014759a0e7b.png` e adicione o arquivo `Curriculo_Pedro_Heitor_TI.pdf` na raiz para o botão **Baixar Currículo** funcionar.
